# AI 종목분석 — 외부 AI 교차 리뷰 기록

> 목적: TotalMoney AI 종목분석 리포트를 **다른 AI 모델들에게 채점받고, 지적을 코드로 고쳐 완성도를 올린 과정**의 기록. 나중에 홍보(“여러 AI가 서로 검수한 리포트”)에 쓴다.
> 대상 리포트: SK하이닉스(000660), 2026-09-26 생성. 채점·의견은 각 모델이 시우에게 준 답을 요약한 것.
> ⚠️ 홍보에 쓸 때 주의: 모델마다 **채점한 리포트 버전이 다르고**(아래 “평가 대상” 참고) 채점 기준도 각자 정했다. 점수를 나란히 놓고 “몇 점 올랐다”고 단정하지 말고, “지적 → 수정” 사례 중심으로 쓰는 게 정확하다. 유사투자자문 규칙상 성과·적중률을 과장하는 표현은 쓰지 않는다.

## 리뷰어별 요약

### 1. Kimi — 91점 (v1 82점 대비 +9)
- 좋았던 점: 과거 유사 국면 통계(“15번 중 11번 상승”)로 **확률에 정량 근거**가 생김. 진입가 구조 통일. 순이익이 영업이익보다 36조 많은 이유(본업 밖 이익)를 스스로 짚음. 실적 발표 예정일 표시.
- 남은 감점: 거시 변수·경쟁사 비교(−4), MACD·볼린저·거래량 이평 부재(−3), “20일 동반 순매도인데 중기 자금이 완전히 놓지 않았다”는 긍정 왜곡(−2).
- 제안: 리포트 끝에 판정 기준을 넣어 성과 달력과 기계적으로 연결 → “100점으로 가는 마지막 한 걸음”.
- **반영**: 보조지표(MACD·볼린저·거래량·ATR) 코드 계산 주입 / 불리한 사실 뒤 위안 문장 금지 규칙 / 매매 계획 아래 **채점 기준** 한 줄(성적표 링크).

### 2. GPT — 82점
- 좋았던 점: 호재와 부담을 같이 놓음, “좋은 뉴스인가”와 “이미 반영됐나”를 구분, 수급을 1·5·20일로 나눔.
- 감점: 40/38/22 확률의 **재현 가능한 계산법 없음**(가장 큰 약점), 표본 15회의 한계·조건 선택 이유 설명 없음, 목표가 203.3만원 산출 근거 없음, 메모리 업종을 PBR만으로 고평가 판단, 업황·컨센서스 수치 부족.
- **반영**: 시나리오 **기준 확률을 코드가 정의대로 계산**(20거래일 뒤 ±5%, 표본 적으면 전체 기간 쪽으로 당김) + AI 조정 ±20%p 제한 + 화면에 기준·최종 나란히 / 표본 한계·조건 이유 문구 / 목표가 = 저항 또는 ATR 1.5배 이상, 손익비 1.5 이상 강제 + 거리 표시 / ROE 병기, 이익 급변 업종은 PER 중심 해석.
- 미반영: D램·HBM 가격, 컨센서스 추이(신뢰할 무료 데이터 없음).

### 3. GPT(초보자 관점) — 78~82점
- 인용 요지: “전문가 수준으로 분석하되, 보여주는 것은 초보자가 이해할 수 있는 것만.”
- **반영**: 요약 카드 맨 위 **좋은 점 / 주의할 점 / 앞으로 이것만 보세요(가격 3개)**, 큰 “상승 확률 40%” → “현재 판단: 강세 우위” 한 마디, 전문용어 첫 등장 시 괄호 풀이(예: MACD(추세의 힘을 재는 지표)), 지표 문장은 결론 먼저·숫자 하나.

### 4. Gemini — 84점 (B+)
- 좋았던 점: 영업외이익 분석의 치밀함, 기술·기본·수급·재료 4축 균형, 9단계 구성.
- 감점: 종합의견은 “눌림 대기”인데 기준안은 190만원 돌파 매수(−5), 목표·손절이 손익비 공식에 맞춘 기계적 값(−2), 시총 1,360조 회사에 1,477억 협력사 수주를 ‘중’ 재료로(−2), 같은 설명 5개 섹션 반복(−1), 표본 한계 언급 없음(−1).
- **반영**: 종합의견 첫 문장을 코드가 “기준 계획 + 대안” 한 문장으로 고정(“190만원 돌파 확인 후 진입, 돌파 전엔 186.3만원 부근 버틸 때만 대안”), AI가 쓴 상충 문장 제거, 계획 옆 돌파형/눌림형 표기 / 재료 강도를 시가총액 대비 비율로(0.1% 미만 ‘하’) / 같은 표현 2회 제한.

### 5. Claude Opus 5.5 — 65점
- 좋았던 점: 계산 정확(수급 환산·손익비·거래일 수), 재료 반영 여부 구분, 용어 풀이, 성적표 공개로 사후 검증 가능.
- 감점: PER 31.6배가 2025년 연간 기준 — 최근 4개 분기면 약 8.4배(−6), 계획-의견 반대(−6), 20일<60일 역배열·3개월 −27.8%인데 “단기·중기 우상향”(−4), 헤드라인 40% vs 자체 통계 87% 설명 없음(−3), 1년 +512.8% vs 52주 저점 모순(−3), 업황 수치 없음(−2), 관망 선택지 없음(−2), 기타 표기(“+1/8”, 단정적 “매수” 라벨 등).
- **반영**: **최근 4개 분기(TTM) PER**을 DART로 계산해 실적 카드·프롬프트에(8.4배 확인) / 이동평균 배열·1·3개월 수익률을 **코드가 확정한 사실**로 넘겨 반대 서술 금지 / 기준 확률 표시 / 약세안 “재진입 검토가”, “종합 +1 (범위 −8~+8)”, “매수 관점”.
- 이미 수정돼 있던 것: 52주 저점 vs 1년 수익률(52주 창 기준으로 변경, 9/28 캐시 재생성 뒤 반영). “K하이닉스” 오타는 붙여넣기 잘림(실제 화면은 정상).

### 6. Claude Opus 5.5 재채점 — 75점 (65 → +10)
- 좋아진 점: 매매 계획과 종합의견 일치, 추세 서술이 데이터와 맞음(역배열 = 중기 복원 전), 재료별 반영률, ATR 기준 목표가, 175만원 이탈 시 관망 선택지, 용어 풀이, 20일 수급 금액 환산.
- 감점: 시장 대비 위치 PER 31.6배(TTM 약 8.4배)에 “가격 부담은 PER 쪽” 문장까지(−6), 1년 +512.8% vs 52주 저점 33.3만원(−3), 확률 근거 순환논리·20일 계획에 5일 통계·87%와 61% 차이 설명 없음(−3), 면책 문구 없음(−2), 자사주 재료 누락(−2), 업황 수치 없음(−2), 손절폭 6.4만원 < ATR 약 10만원·추세 점수 만점 등(−7). 별도로 “같은 입력에 A 40%→61%”는 유료화 시 신뢰 문제.
- **반영(세션 10)**: 시장 대비 위치 PER을 **최근 4개 분기 기준**으로 교체(8.40배, 중앙값보다 낮음) + ROE 문장 대신 사실 문장 / 확률 조정폭 **±10%p**로 축소 / A안 근거 첫 문장을 코드가 “과거 15회 중 20거래일 뒤 13회(87%) 상승, A는 +5% 이상만 세므로 더 낮게 잡힘 — 표본 적어 참고용”으로 고정, “기준 N%가 맞다” 류 문장 자동 삭제 / 손절폭 최소 **ATR 1배**(A 손절 183.6만 → 179.5만) / 20일선<60일선이면 추세 점수 +1 상한 / 재료·업황은 확인된 숫자·날짜만(자사주 소각 재료 복귀) / 면책 문구에 “누구에게나 같은 내용, 개인별 상담 없음, 확률·통계·성적표는 수익 보장 아님” / “상승 확률” → “강세 시나리오 추정(AI 추정치)”.
- 추가로 잡은 것(재생성하며 발견): B안이 A안과 가격이 똑같이 나오는 경우 → B는 현재가 부근 진입으로 / 종합의견에서 AI 옛 매매가를 새 숫자로 바꿔 끼워 뜻이 뒤틀리던 문제(“205.8만원은 되돌림을 받아낼 자리”) → 그런 문장은 삭제 / “현재가가 1,900,000원이라” 오기 교정 / 한눈에 보기에서 현재가 위 가격에 “지키면” 쓰는 오류 교정 / OpenAI 응답 JSON 깨짐 자동 복구.
- 참고: 채점 대상 화면은 브라우저에 남아 있던 **옛 화면 스크립트**로 그려져 “종합 +1/8”, “매수” 라벨, 면책 문구 누락 등 이미 고친 항목이 보였다. 1년 수익률은 코드 수정 완료, 추석 휴장으로 스크리너 캐시가 9/23 그대로라 **9/28(월) 16:00 재생성 뒤 반영**.
