## 1. 구글 로그인 (10분)

### 1-1. Google Cloud Console에서 OAuth 클라이언트 만들기
1. https://console.cloud.google.com → 프로젝트 선택(없으면 새로 만들기)
2. 좌측 **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부(External)** → 만들기
   - 앱 이름 `TotalMoney AI`, 지원 이메일 `totalmoneyai@gmail.com`
   - 승인된 도메인에 `totalmoney.kr` 과 `supabase.co` 추가
   - 저장 후 **게시 상태 → 프로덕션으로 게시** (테스트 모드면 등록한 사람만 로그인됨)
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 유형: **웹 애플리케이션**
   - **승인된 리디렉션 URI** 에 아래 한 줄 입력
     ```
     https://slcplrblmdiydakwzqdc.supabase.co/auth/v1/callback
     ```
   - 만들기 → **클라이언트 ID / 클라이언트 보안 비밀번호** 복사

### 1-2. Supabase에 붙여넣기
1. https://supabase.com/dashboard → 프로젝트 → **Authentication → Sign In / Providers**
2. **Google** 켜기 → Client ID / Client Secret 붙여넣기 → Save

## 2. 카카오 로그인 (15분)

### 2-1. 카카오 개발자센터
1. https://developers.kakao.com → **내 애플리케이션 → 애플리케이션 추가하기**
   - 앱 이름 `TotalMoney AI`, 사업자명 입력
2. **앱 설정 → 플랫폼 → Web 플랫폼 등록**
   - 사이트 도메인: `https://www.totalmoney.kr`
3. **제품 설정 → 카카오 로그인** → 활성화 **ON**
   - **Redirect URI** 등록:
     ```
     https://slcplrblmdiydakwzqdc.supabase.co/auth/v1/callback
     ```
4. **제품 설정 → 카카오 로그인 → 동의항목**
   - **닉네임**: 필수 동의
   - **카카오계정(이메일)**: 필수 동의 ← ⚠️ 이게 없으면 계정을 못 만듭니다
   - 이메일 필수 동의는 **비즈 앱 전환**이 필요할 수 있습니다(사업자등록 후 진행).
     당장은 "선택 동의"로 두고, 사용자가 이메일 제공에 동의하면 정상 가입됩니다.
5. **앱 설정 → 앱 키** 에서 **REST API 키** 복사
6. **제품 설정 → 카카오 로그인 → 보안** 에서 **Client Secret 생성 → 활성화 상태 ON** → 코드 복사

### 2-2. Supabase에 붙여넣기
**Authentication → Sign In / Providers → Kakao** 켜기
- Client ID = **REST API 키**
- Client Secret = 위에서 만든 **Client Secret 코드**

## 3. 네이버 로그인 (30분 · 조금 복잡)

네이버는 Supabase가 기본 지원하지 않습니다. 그리고 **Vercel Hobby 플랜은 배포당 서버리스 함수가
12개 제한인데 이미 12/12로 꽉 차 있어서** Vercel에 새 API를 못 만듭니다.
그래서 서버 코드를 **Supabase Edge Function** 으로 뺐습니다. (Vercel 함수 개수에 영향 없음)

### 3-1. 네이버 개발자센터 앱 등록
1. https://developers.naver.com → **Application → 애플리케이션 등록**
   - 애플리케이션 이름: `TotalMoney AI`
   - 사용 API: **네이버 로그인**
   - **제공 정보 선택: 이메일 주소(필수), 별명** ← 이메일이 없으면 로그인 불가 처리됩니다
   - 환경: **PC 웹**
   - 서비스 URL: `https://www.totalmoney.kr`
   - **Callback URL**:
     ```
     https://slcplrblmdiydakwzqdc.supabase.co/functions/v1/naver-auth
     ```
2. 등록 후 **Client ID / Client Secret** 확인

### 3-2. Edge Function 배포
저장소의 `supabase/functions/naver-auth/index.ts` 를 배포합니다.
Supabase 대시보드에서도 되고, CLI로도 됩니다.

**CLI 방식**
```bash
npm i -g supabase
supabase login
cd D:\vibe
supabase functions deploy naver-auth --no-verify-jwt --project-ref slcplrblmdiydakwzqdc
```
> `--no-verify-jwt` **필수**. 네이버가 인증 헤더 없이 브라우저를 통해 호출하기 때문입니다.

**대시보드 방식**: Edge Functions → Deploy a new function → 이름 `naver-auth`,
`index.ts` 내용 붙여넣기 → 함수 설정에서 **Verify JWT 끄기**

### 3-3. Secrets 등록
Supabase 대시보드 → **Edge Functions → Secrets** (또는 Project Settings → Edge Functions)

| 이름 | 값 |
|---|---|
| `NAVER_CLIENT_ID` | 네이버 Client ID |
| `NAVER_CLIENT_SECRET` | 네이버 Client Secret |
| `TM_SITE_URL` | `https://www.totalmoney.kr` |

> ⚠️ `NAVER_CLIENT_SECRET` 은 **절대** `assets/auth-config.js` 같은 프론트 파일에 넣지 마세요.

### 3-4. 프론트에 Client ID 넣기 (이걸 해야 버튼이 나옵니다)
`assets/auth-config.js` 의 `NAVER_CLIENT_ID: ""` 에 **Client ID만** 넣고 저장 → GitHub push.
(Client ID는 공개되어도 되는 값입니다. Secret은 절대 안 됩니다.)

## 4. 비밀번호 정책을 서버에도 적용 (2분 · ⚠️ 꼭 하세요)

지금 페이지에서는 8자+영문숫자를 강제하지만, **Supabase 서버는 아직 6자도 통과시킵니다.**
API를 직접 두드리면 뚫리므로 서버 설정도 맞춰야 진짜 적용입니다.

Supabase 대시보드 → **Authentication → Sign In / Providers → Email** (또는 Policies)
- **Minimum password length**: `8`
- **Password Requirements**: `Letters and digits` (영문+숫자)
- **Leaked password protection**: **ON** 권장
  → 이미 유출된 적 있는 비밀번호(HaveIBeenPwned 목록)를 자동 거부합니다. 무료이고 효과가 큽니다.

## 6. 확인 방법

1. https://www.totalmoney.kr/signup.html → 구글/카카오(설정했다면 네이버) 버튼 클릭
2. 로그인 후 `auth-callback.html` 을 거쳐 마이페이지로 이동하면 성공
3. 소셜 최초 가입자는 **약관 동의 페이지(consent.html)** 를 한 번 거칩니다
4. https://www.totalmoney.kr/reset-password.html 에서 본인 이메일로 재설정 메일 테스트

**증상별 원인**
| 증상 | 원인 |
|---|---|
| 로그인 후 "요청한 경로를 찾을 수 없음" | 5단계 Redirect URLs 누락 |
| 구글에서 "이 앱은 확인되지 않았습니다" | OAuth 동의 화면이 테스트 모드 → 프로덕션 게시 |
| 카카오 "이메일 제공 동의 필요" | 2-1의 동의항목에서 이메일 켜기 |
| 네이버 버튼이 안 보임 | 3-4의 `NAVER_CLIENT_ID` 가 비어 있음 |
| 네이버에서 "설정되지 않았습니다" | 3-3의 Secrets 누락 |

## 7. 나중에 검토할 것 (지금은 불필요)

- **애플 로그인**: iOS 앱을 낼 계획이 생기면. Apple 개발자 계정 연 $99 필요.
- **2단계 인증(MFA)**: 유료 결제가 열리고 계정에 돈이 걸리면 그때. Supabase가 TOTP를 기본 지원.
- **CAPTCHA**: 가입 스팸이 실제로 생기면. Supabase Auth에 hCaptcha/Turnstile 연동 옵션 있음.
- **로그인 시도 제한**: Supabase가 기본 rate limit을 걸어두고 있어 당장은 추가 조치 불필요.
