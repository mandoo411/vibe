# 운영 점검 시퀀스 (2026-09-24 재정리)

텔레그램 운영 알림(개인 DM)은 **두 곳에서만** 나간다. 한 가지 문제는 한 곳에서만 알린다.

| 담당 | 파일 | 언제 | 무엇을 |
|---|---|---|---|
| **점검봇** | `scripts/health-check.mjs` (`health-check.yml`) | 매시 5분 | 아래 표의 12개 항목 |
| **마감 워치독** | `scripts/check-daily-report-watchdog.mjs` (`daily-report-watchdog.yml`) | 거래일 16:40(1차) · 19:00(최종) | 시세 동기화 누락 / 마감 리포트 누락 |

"거래일인가"는 전부 `lib/krx-calendar.js`(한국거래소 휴장일 달력) 한 곳에서 판단한다.
공휴일·명절·선거일·연말 휴장일에는 한국 증시 관련 작업과 점검이 모두 조용히 쉰다.

## 점검봇 항목 (매시간 돌지만, 항목마다 볼 시각이 정해져 있다)

| 구분 | 볼 시각(KST) | 항목 |
|---|---|---|
| 매일 | 매시간 | 글로벌랭킹 API 응답·종목 수·삼성/하이닉스 이상치 |
| 매일 | 매시간 | 실시간시세 조회(삼성전자) — KIS 토큰·연결 |
| 매일 | 매시간 | package.json 문법 |
| 매일 | 09시대 1회 | 휴장일 달력 유지보수(11월부터 내년 달력 확인) |
| 평일 | 08:30~ | 아침 브리핑 수치 자체 점검(errors) |
| 평일 | 09:00~ | 아침 브리핑 AI 분석 발행(Cowork 08:03) |
| 평일 | 09:00~ | 인스타 아침 카드 발행 |
| 거래일 | 09:40~ | 종가시그널: 직전 거래일 선정분 결과 기록(16:10 이후엔 종가 확정까지) |
| 거래일 | 15:40~ | 종가시그널: 오늘 15:20 랭킹 생성 |
| 거래일 | 16:00~ | 마감시황 지수 등락률 이상치 |
| 거래일 | 18:30~ | 인스타 마감 카드 — 리포트는 있는데 발행 안 된 경우만(리포트 누락은 워치독) |
| 토요일 | 11:30~ | 인스타 주간 랭킹 카드 |

- 평일 = 미국장 기반이라 한국 휴장일에도 나가는 것(아침 브리핑·아침 카드).
- 거래일 = 한국 증시가 열린 날만.
- 같은 문제가 계속되면 3시간마다 다시 알림, 해소되면 "정상화" 1회.
- 항목 목록은 `node scripts/health-check.mjs --list`로 언제든 볼 수 있다.
